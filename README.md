# 메타시티 아레나 오픈 방명록 키오스크 (2026-11-07)

패드에 띄워 두는 도트 게임형 방명록입니다. 파일은 `index.html` + `assets/`(로고 SVG 3개)뿐입니다.

흐름: 시작 화면 → 선수 만들기(사진 / 자동 생성) → 승부차기 3번 → 설문 3문항 → 방명록 한마디 → GAME CLEAR → 구장에 캐릭터가 쌓여 함께 뜁니다.
세로 · 가로 둘 다 됩니다(패드를 돌리면 구장이 바로 바뀝니다).

## 정한 것

| 항목 | 방식 | 이유 |
|---|---|---|
| 사진 → 캐릭터 | 브라우저 안에서 얼굴 원 안의 피부 · 머리 · 옷 색을 뽑아 32비트풍 도트 선수(2026 디아도라 홈 · 원정 유니폼)에 입힘 | 와이파이 · 비용 · 대기 0, 아이 얼굴을 외부로 보내지 않음 |
| 원본 사진 | 저장하지 않음(변환 직후 메모리에서 지움) | 개인정보 최소 수집 |
| 저장 | 패드 브라우저 IndexedDB. 관리자 화면에서 CSV · JSON · 캐릭터 모음 PNG로 내려받기 | 서버 없이 오프라인 동작 |
| 동의 | 사진 경로에만 촬영 안내 + 동의 체크. 자동 생성은 사진 없이 참여 | |

보관 기간 "행사 뒤 3개월 안에 지웁니다"는 제안값입니다. 클럽과 확정해 주시기 바랍니다.

## 띄우는 곳

카메라는 **https 주소**에서만 켜집니다. GitHub Pages · Netlify 같은 https 정적 호스팅에 이 폴더를 그대로 올리면 됩니다.
- 기록은 패드마다 그 기기 브라우저에만 쌓입니다(호스팅 서버로 가지 않습니다). 패드가 여러 대면 각각 내려받습니다.
- 처음 열 때만 인터넷이 필요합니다(폰트 CDN 포함). 열어 둔 뒤에는 와이파이가 끊겨도 돌아가지만 **새로고침은 하지 않습니다**.

## 행사 당일

1. 전날: 패드에서 주소를 열고 → 사진 경로를 한 번 해 보며 카메라 권한 "허용" → 관리자 화면에서 **전체 지우기**(테스트 기록 삭제).
2. iPad: Safari 공유 → **홈 화면에 추가** → 홈 화면 아이콘으로 실행(전체화면). 설정 → 손쉬운 사용 → **사용법 유도(Guided Access)** 켜고 홈 버튼 3번으로 잠금. 자동 잠금 "안 함".
   - 홈 화면 앱과 Safari 탭은 저장소가 따로입니다. 한 가지로만 운영하고 내려받기도 같은 곳에서 합니다.
3. Android: Chrome 메뉴 → 홈 화면에 추가, 설정에서 **앱 고정(화면 고정)**. 화면 꺼짐은 페이지가 막습니다.
4. 소리: 오른쪽 위 ♪ 버튼으로 배경음 켜고 끔(설정은 기억됨). 처음 한 번 화면을 눌러야 소리가 납니다.
5. 행사 중 2~3시간마다 관리자 → **CSV · JSON 내려받기**로 백업합니다.
6. 끝나면 CSV(엑셀) · JSON(백업) · 캐릭터 모음 PNG를 내려받습니다.

## 관리자 화면

- 왼쪽 위 MTCT 로고를 **2초 누르기** → PIN `1107`. 또는 주소 끝에 `?admin`.
- 오래(90초) 손대지 않으면 처음 화면으로 돌아갑니다. 중간에 떠난 참가자는 저장되지 않습니다.
- 오른쪽 위에 "⚠ 저장 안 됨"이 보이면 개인정보 보호(시크릿) 모드인지 확인합니다.
